# Randly 3.0

Статический сервис случайного выбора на русском языке: числа, колесо, списки, команды, монетка, кости, да/нет и перемешивание. Не требует учётной записи или backend. История, настройки и наборы колеса хранятся в localStorage текущего браузера.

## Что было в исходном проекте

Архив `randly_randomizer_v2.zip` содержал одну HTML-страницу и монолитный `app.js`: числовой генератор и колесо. Уже были rejection sampling для 32-битного диапазона, история, исключения, веса и демо-режим. Диапазон был ограничен ±999999 и 2 млн значений; колесо визуализировало числа до 32 секторов. Развитие ограничивали отсутствие тестов и модульной границы, жёсткое ограничение диапазона, а также тесная связь визуализации колеса с числовыми весами. Randly 3.0 оставляет проект статическим и выносит алгоритмы случайного выбора в `random-core.js`.

## Запуск на VPS

Выполните `docker compose up -d --build`. Контейнер доступен только на `127.0.0.1:8788`; подключите внешний Caddy/Nginx reverse proxy и настройте HTTPS на нём. Для подпути используйте проксирование `/randly/` на `http://127.0.0.1:8788/`; ресурсы приложения подключены относительно страницы.

Обновление: `git pull && docker compose up -d --build`. Диагностика: `docker compose ps`, `docker compose logs --tail=100 randly`, `curl -fsS http://127.0.0.1:8788/health`. Остановка: `docker compose down`. Контейнер работает непривилегированным пользователем с read-only root filesystem, без Linux capabilities и с healthcheck.

## Разработка и проверки

Откройте `index.html` в современном браузере или запустите локальный HTTP-сервер из каталога проекта. Основные проверки случайной логики: `node --test tests/random-core.test.cjs`. Требуется Node.js 18+; runtime сайта не требует Node.js.

Алгоритмы используют `crypto.getRandomValues` с rejection sampling без modulo bias. Числовой диапазон может включать отрицательные значения и безопасные целые JavaScript. Без повторов выбор делается за ограниченное число шагов, без случайного перебора до успеха. Веса чисел задаются в настройках как `3:5, 7:2`; для списка — суффиксом `Имя|3` в строке. Незаписанные числа/элементы имеют вес 1, вес 0 исключает значение. Колесо оставляет равные шансы секторам. Пользовательский текст выводится безопасно.

## Ограничения

Сохранённые наборы колеса доступны через команды «Сохранить набор» и «Загрузить набор». История экспортируется в JSON. Поделиться настройками через URL и полноценная английская локализация пока не реализованы. Сброс локальной истории доступен в интерфейсе.
